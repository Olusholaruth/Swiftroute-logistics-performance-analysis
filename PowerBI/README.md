# Power BI Report

Place the final SwiftRoute Power BI Desktop report (.pbix) in this folder.

The supplied capstone brief requires eight KPI cards:

- Total Revenue
- Total Profit
- Total Shipments
- Total Delay Days
- Late Shipment Rate
- Lagos Revenue
- Lagos Delayed Shipments
- South West Delay Days

It also specifies trend, regional, category, carrier, delivery-status, service, city, customer-type and distance-performance analysis, with interactive slicers.

Open the PBIX in Power BI Desktop to inspect the report and interact with its filters. The KPI definitions should be read with `../Documentation/methodology-and-kpis.md`.
