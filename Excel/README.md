# Excel Workbook

<escape>[Download the Excel project workbook](https://github.com/Olusholaruth/Swiftroute-logistics-performance-analysis/releases/download/v1/EXCEL.SWIFTROUTE.LOGISTICS.PROJECT.UPTIMIZED.2.zip)</escape> — the ZIP is attached to [Release v1](https://github.com/Olusholaruth/Swiftroute-logistics-performance-analysis/releases/tag/v1).

The workbook is documented as containing five worksheets:

1. **SwiftRoute_Logistics_Portfolio_** — raw dataset (100,000 rows including the header; 20 columns).
2. **SwiftRoute_Logistics Cleaned ** — prepared dataset (98,000 rows including the header; 20 columns).
3. **Aggregation Question** — conditional calculations and service/customer summaries.
4. **Summary Analysis** — written management observations and recommendations.
5. **Pivot Table** — regional revenue, package-category profitability, carrier performance and monthly performance summaries.

The workbook is the evidence source for the Excel results documented in this repository. Review the formulas, PivotTables and underlying data before relying on a result.
