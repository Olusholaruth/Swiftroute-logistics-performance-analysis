# SwiftRoute Logistics — Operations & Financial Performance Analysis

An end-to-end business analytics capstone examining logistics operations and financial performance using Microsoft Excel and Power BI.

## Project overview

SwiftRoute Logistics is a case-study logistics business. This project takes shipment-level data through data preparation, Excel analysis, KPI development, and interactive Power BI reporting to support operational and financial decision-making.

**Business questions**
- How are revenue and profit distributed across regions, carriers, services, and package categories?
- Which carriers and service types perform better financially and operationally?
- Where are delivery delays concentrated?
- How do shipment volume, delivery outcomes, and distance relate to performance?

## Tools

- **Microsoft Excel** — data review, analysis, conditional calculations, and PivotTables
- **Power Query** — data preparation and transformation
- **Power BI** — DAX measures, KPI reporting, interactive dashboard
- **SQL / Python** — not claimed as tools used in this project

## Analysis scope

- Data-quality review: duplicate records, inconsistent categorical values, and data types
- Financial analysis: revenue, profit, shipping cost, and performance by business dimension
- Operations analysis: shipment volume, delivery status, delay days, and carrier performance
- Dashboard KPIs: total revenue, total profit, unique shipments, delay days, late shipment rate, and selected location/region measures
- Interactive exploration by region, carrier, service type, package category, and customer type
